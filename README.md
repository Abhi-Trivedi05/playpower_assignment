# Playpower Assignment - Airbnb Listing Experience

A pixel-perfect, responsive replica of the Airbnb property listing page for Candolim, Goa. Built with React and modern CSS.

## Features
- **Header & Navigation**: Fixed search widget, brand branding, interactive sticky sub-nav with active section indicator tracking scroll position.
- **Photo Gallery**: Desktop multi-photo grid layout with "Show all photos" modal walkthrough.
- **Listing Details & Badges**: Authentic Guest Favourite laurel badge, verified host card, detailed amenities breakdown.
- **Dual Month Interactive Calendar**: October & November 2026 booking calendar with custom connected range pill styling, disabled past/unavailable dates, and night counter.
- **Reservation Card**: Sticky dynamic pricing widget reflecting selected dates, guest counters, and discount vouchers.
- **Reviews & Ratings**: Category bar breakdowns, scrollable review tags, verified user testimonials, and reviews modal.
- **Location & Things to Know**: Custom interactive location map, cancellation policy, house rules, and safety information with modal details.

## Tech Stack
- **React 18**
- **Vite**
- **Lucide Icons**
- **Vanilla CSS**
